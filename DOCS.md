# Generated API documentation

The [online reference](https://carlos-sweb.github.io/z-date/) is generated by Zig
0.17 from the library's `//!` module comments and `///` declaration comments.
It includes API signatures, parameter types, documented behavior, ownership,
errors and source navigation. It uses Zig's original documentation interface.

## Build and browse locally

```bash
zig build docs
python3 scripts/prepare_docs.py
python3 -m http.server 8000 --directory zig-out/docs
```

Open http://localhost:8000/. Keep `index.html`, `main.js`, `main.wasm` and
`sources.tar` together: the browser loads the WebAssembly module and source
archive over HTTP. Opening `index.html` with `file://` does not provide that
HTTP environment.

`prepare_docs.py` sets the page title from the package version and adds
`.nojekyll`; it does not replace Zig's generated API interface.

## Coverage and maintenance

All **155 public functions** in `src/*.zig` have Zig doc comments. This includes
107 root-exported functions and 48 implementation helper functions. Aliases,
record fields, constructors, ownership and error contracts are described in
the reference; concise getters/setters retain concise comments. The signatures
provide the actual Zig parameter types.

```bash
python3 scripts/check_docs.py
zig build test --summary all
```

The coverage check detects missing function comments; it does not prove that a
comment is correct. Review comments with their implementation and keep examples
compilable. The README and API reference describe the current formatting and
arithmetic limitations rather than promising unsupported behavior.

## GitHub Pages

`.github/workflows/docs.yml` runs after pushes to `master` and supports manual
`workflow_dispatch`. It installs Zig 0.17.0, runs the 310 tests and coverage
check, generates the reference, uploads `zig-out/docs`, and deploys through the
`github-pages` environment. The workflow follows GitHub's
[custom Pages workflow](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

GitHub Pages must use **GitHub Actions** as its publishing source. No generated
18 MB source archive is committed to the main branch; generated files are
published as a Pages artifact. The published root is:

https://carlos-sweb.github.io/z-date/
